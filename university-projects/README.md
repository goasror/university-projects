# University Projects

Course projects from Inha University in Tashkent, spanning machine learning, robotics, UX design and product design. Each folder has its own README with details, results and media.

| Project | Area | Highlights |
| --- | --- | --- |
| [Dr. XRayDetect](xray-pneumonia-detection/) | Deep learning | Pneumonia detection from chest X-rays with 3 CNNs (best: 92.3% recall, 0.946 AUC), LIME explanations, Telegram bot |
| [TurtleBot3 AutoRace](turtlebot3-autorace/) | Robotics, computer vision | Camera-based lane following with a 3-stage state machine and PD control; full lap in 3:55 with zero line crossings |
| [iFood](ifood-app-design/) | UX / product design | Food delivery and table booking app: 39-person survey, QFD, user flows, wireframes, clickable Figma prototype |
| [Adjustable device stand](stand-design/) | Product design | Foldable stand with angle-adjustable prop and rotating base, from sketches to paper prototype |

**Tech:** Python · TensorFlow/Keras · scikit-learn · LIME · python-telegram-bot · ROS · OpenCV · Gazebo · Figma
